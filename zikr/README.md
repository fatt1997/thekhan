# ตัวนับซิกิร

เว็บแอปนับซิกิร แยกหมวดตามเวลาละหมาด 5 เวลา แต่ละหมวดมีหลายบท แต่ละบทตั้งจำนวนครั้งเองได้

- แตะที่ไหนก็ได้บนจอเพื่อนับ เมื่อครบจะสั่นแล้วไปบทถัดไปเอง
- ปัดซ้าย = บทถัดไป, ปัดขวา = บทก่อนหน้า
- ปุ่มดินสอ = แก้ชื่อหมวด เพิ่ม/ลบ/สลับบท ตั้งจำนวนครั้ง
- "วางหลายบทพร้อมกัน" ใส่บรรทัดละบท เช่น `سبحان الله | 33`
- การนับเริ่มใหม่ทุกวันเอง
- เข้าสู่ระบบด้วย Google (หน้าตั้งค่า) แล้วข้อมูลจะซิงก์กับ Google Drive ข้ามเครื่อง
  เก็บเป็นไฟล์ `zikr.json` ในพื้นที่ซ่อนของแอปใน Drive ใช้ Client ID เดียวกับแอปที่คั่น
- เพิ่มไปหน้าจอโฮมบน iPhone ได้ ใช้ออฟไลน์ได้
