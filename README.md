# ที่คั่น

เว็บแอปอ่าน PDF ส่วนตัว สำหรับใช้ในครอบครัว ไฟล์และบุ๊กมาร์กเก็บใน Google Drive ของผู้ใช้แต่ละคน

## ความสามารถ

- เพิ่มไฟล์ PDF เก็บไว้ในเครื่อง เปิดอ่านได้แม้ไม่มีอินเทอร์เน็ต
- จัดหนังสือใส่แฟ้ม ซ้อนแฟ้มย่อยได้ไม่จำกัดชั้น
- ปกหนังสือสร้างจากหน้าแรกของไฟล์
- อ่าน 2 โหมด คือ ปัดซ้าย-ขวา และ เลื่อนขึ้น-ลง จำโหมดแยกแต่ละเล่ม
- บุ๊กมาร์ก 2 แบบ
  - บุ๊กมาร์กถาวร บันทึกหน้าสำคัญ ใส่โน้ตได้ มีได้หลายหน้า
  - หน้าที่อ่านถึง กดบันทึกเอง เก็บเป็นประวัติ ล่าสุดอยู่ล่างสุด
- ซิงก์ไฟล์และบุ๊กมาร์กกับ Google Drive ข้ามอุปกรณ์
- ล็อกอินหลายบัญชีในเครื่องเดียวกันได้ ข้อมูลแต่ละคนแยกกัน

## โครงสร้างไฟล์

```
index.html       โครงหน้าเว็บ
manifest.json    ข้อมูลแอปสำหรับเพิ่มไปหน้าจอโฮม
css/style.css    สีและการจัดหน้า
icons/           ไอคอนแอป
js/
  config.js      Client ID และค่าตั้งต้น
  app.js         เริ่มแอป สลับหน้าจอ
  auth.js        ล็อกอิน Google
  db.js          IndexedDB ในเครื่อง
  drive.js       เรียก Google Drive API
  sync.js        รวมข้อมูลเครื่องกับ Drive
  library.js     ชั้นหนังสือ แฟ้ม ปก
  render.js      วาดหน้า PDF ปก และภาพย่อ
  reader.js      หน้าอ่าน 2 โหมด
  marks.js       บุ๊กมาร์ก 2 แบบ
  ui.js          แผ่นเลื่อนขึ้น ข้อความแจ้งเตือน
```

## เทคโนโลยี

HTML, CSS, JavaScript ล้วน ไม่ใช้ framework ใช้ไลบรารีภายนอก 2 ตัว คือ PDF.js สำหรับอ่าน PDF และ Google Identity Services สำหรับล็อกอิน

## การติดตั้ง

1. สร้างโปรเจกต์ใน Google Cloud เปิดใช้ Google Drive API และสร้าง OAuth Client ID แบบ Web application
2. ใส่ Client ID ในไฟล์ `js/config.js`
3. เพิ่มที่อยู่เว็บใน Authorized JavaScript origins ของ Client ID
4. เปิดเว็บผ่าน https หรือ localhost เท่านั้น

## ข้อมูลถูกเก็บที่ไหน

- ไฟล์ PDF และภาพย่อ เก็บใน IndexedDB ของเบราว์เซอร์ แยกฐานข้อมูลตามบัญชี
- ไฟล์ PDF ต้นฉบับ เก็บในโฟลเดอร์ `ที่คั่น` ใน Google Drive ของผู้ใช้
- บุ๊กมาร์ก เก็บในไฟล์ `library.json` ในโฟลเดอร์ซ่อน appDataFolder ของผู้ใช้

แอปใช้สิทธิ์ `drive.file` จึงเห็นเฉพาะไฟล์ที่แอปสร้างเอง ไม่เห็นไฟล์อื่นในไดรฟ์ของผู้ใช้
